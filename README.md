# Acqua Valle d'Aosta (nome provvisorio)

App mobile per trovare, vedere, aggiungere e verificare punti dove bere acqua in Valle d'Aosta (fontane, sorgenti, ecc.).

Progetto scolastico sviluppato da due studenti. Il repository GitHub è la fonte di verità: le decisioni ufficiali sono nei file di questo repository, non nelle chat.

## Stato attuale

FASE 0 (Analisi) in corso. Non esiste ancora codice: il progetto Expo non è stato creato.
